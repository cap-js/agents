# Skill: Response Format

Internal skill — not advertised in the agent card.

## Rules

- Always show prices with 2 decimal places and $ prefix
- Use markdown bold for product names
- Include stock status in every product mention
- Format order confirmations with bullet points
- Use volume discount tier names: standard, volume (10+), bulk (50+), enterprise (100+)
